## Final Test Specification

### What This Test Should Verify

This test verifies users can perform CRUD operations on Tags and link them to various task types:
- Navigate to Tags admin page
- Create new Tag
- View Tags in grid
- Edit Tag
- Link Tag to Core Task
- Link Tag to Diverted Task
- Link Tag to Downtime
- Delete Tag

### Prerequisites
- **User:** User from 9000-9199 range (UI tests)
- **Permissions:** Admin access to /admin/tags
- **Pre-seeded Tasks:**
  - Core Task for linking
  - Diverted Task for linking
  - Downtime for linking

### Test Steps

#### Create Tag
1. Navigate to `/admin/tags`
   - **Expected:** Tags grid displays
2. Click "Add New"
   - **Expected:** Create form/dialog appears
3. Fill form:
   - **Name:** `Test Tag ${Guid}`
   - **Description:** Test description
   - **Other fields as required**
4. Submit
   - **Expected:** Success message
   - **Expected:** Tag appears in grid

#### View Tags
5. Verify created Tag visible in grid
   - **Expected:** Row shows Tag name and details
6. Use search/filter if available
   - **Expected:** Can find specific tags

#### Edit Tag
7. Click Edit for created Tag
   - **Expected:** Edit form appears with current values
8. Modify Name and Description
9. Submit changes
   - **Expected:** Success message
   - **Expected:** Grid updates with new values

#### Link Tag to Core Task
10. Access tag linking interface (may be on Tags page or Core Tasks page)
11. Select created Tag and a pre-seeded Core Task
12. Confirm linking
    - **Expected:** Success message
    - **Expected:** Link visible in UI

#### Link Tag to Diverted Task
13. Select created Tag and a pre-seeded Diverted Task
14. Confirm linking
    - **Expected:** Success message
    - **Expected:** Link visible in UI

#### Link Tag to Downtime
15. Select created Tag and a pre-seeded Downtime
16. Confirm linking
    - **Expected:** Success message
    - **Expected:** Link visible in UI

#### Delete Tag
17. Click Delete for test Tag
    - **Expected:** Confirmation dialog
18. Confirm deletion
    - **Expected:** Success message
    - **Expected:** Tag removed from grid

### Expected Results
- User can successfully create Tags via UI
- Tags visible in grid with all details
- Edit changes persist correctly
- Tags can be linked to Core Tasks, Diverted Tasks, and Downtime
- Delete removes Tag from system
- All operations show appropriate success/error messages
